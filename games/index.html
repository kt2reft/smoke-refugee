ABOUT

ここは kt2reft が個人で作っているブラウザゲームの公開ページです。販売はしていません。すべて無料で、ダウンロードもアカウント登録も必要ありません。カードを押すと詳細、「遊ぶ」を押すとその場でゲームが始まります。

インストール不要ブラウザだけで動きます。リンクを送れば、相手もそのまま遊べます。
PC・スマホ・パッドキーボード＋マウス、タッチ操作、ゲームパッドに対応（作品により異なります）。
みんなで遊べる同じ画面での協力・対戦や、招待リンクで繋がるオンラインに対応した作品があります。
ソースも公開各作品のソースコードは GitHub で見られます。
